# Nina et Michelle — The Fine Art of Basics

אתר סטטי (HTML/CSS/JS בלבד — בלי Build) לחנות הבגדים Nina et Michelle, לפי עיצוב המוקאפים.

## מבנה

| קובץ | תיאור |
|---|---|
| `index.html` | דף הבית — Hero, שני אריחי תוכן, רצועת Journal, פוטר מלא |
| `journal.html` | עמוד ה-Journal עם הכתבות המובלטות והגריד |
| `journal-atelier.html` | כתבה: Inside the Atelier |
| `journal-natural-fabrics.html` | כתבה: The Beauty of Natural Fabrics |
| `journal-paris.html` | כתבה: Paris, Always |
| `shop.html` | עמוד חנות (Tops / Bottoms / Sets) |
| `collections.html` | עמוד קולקציות |
| `about.html` | הסיפור שלנו |
| `contact.html` | יצירת קשר |
| `css/style.css` | כל העיצוב (פלטת קרם/שחור, EB Garamond) |
| `js/main.js` | תפריט מובייל + טפסים |
| `images/` | atelier.jpg, fabric.jpg, paris.jpg |

## מה נשאר להשלים (מסומן `TODO` בקוד)

- תמונות מוצרים בעמוד ה-Shop (כרגע מלבנים בגוני קרם עם סימן N·M; ל-Everyday Set כבר יש תמונה).
- תמונות ל"Everyday Rituals" ו"The Details Matter" ב-Journal + הטקסטים המלאים לשלוש הכתבות הקטנות.
- מחירים אמיתיים (כרגע מחירי דוגמה ב-₪ — קל להחליף).
- פרטי קשר אמיתיים (אימייל, אינסטגרם) ועמודי תקנון/פרטיות.
- חיבור סל קניות/סליקה כשיוחלט על פלטפורמה.

## הרצה מקומית

פשוט לפתוח את `index.html` בדפדפן, או:

```bash
python3 -m http.server 8000
```

ולגלוש אל http://localhost:8000
